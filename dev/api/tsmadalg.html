tsmadalg

tsmadalg provides the algorithm registry, CLI, and concrete algorithm implementations built on top of tsmadkit.

Package

Registry and CLI

Algorithm discovery and registry.

Algorithm packages are discovered in the tsmadalg.algorithms package directory. Additional local/developer algorithm folders can be discovered by setting TSMADALG_EXT_PATH to a list of directories, separated by the platform path separator (: on Linux/macOS, ; on Windows). Each directory listed there is treated like an additional algorithms root.

tsmadalg.tools.registry.list_algorithms(include_unavailable: bool = True) → dict[str, dict[str, object]][source]

Discover and import all anomaly detection algorithms, and return their registry entries.

Parameters:

include_unavailable (bool, default=True) – If False, only return algorithms whose implementation imported successfully.

Returns:

A dictionary where each key is the algorithm name and each value is a dictionary containing:

  • ”name”: the algorithm name

  • ”module”: the dotted module path of the algorithm’s main.py

  • ”class”: the algorithm class reference (subclass of AnomalyDetection), or None if discovery failed

  • ”version”: the algorithm version declared in the class attribute __version__, or None if discovery failed

  • ”status”: either “available” or “unavailable”

  • ”source”: path to the directory containing the algorithm’s main.py

  • ”error_type”: the exception type name raised during discovery, or None if discovery succeeded

  • ”error_message”: the exception message raised during discovery, or None if discovery succeeded

Return type:

dict[str, dict[str, object]]

tsmadalg.tools.registry.get_algorithm_class(name: str) → type[AnomalyDetection][source]

Return the algorithm class for a discovered and available algorithm. The class should inherit from AnomalyDetection. Only this algorithm is imported.

Parameters:

name (str) – The name of the algorithm to load.

Returns:

The loaded anomaly detection algorithm class that inherits from AnomalyDetection.

Return type:

type[AnomalyDetection]

Raises:

ValueError –

  • If the specified algorithm name is not found. - If the algorithm is unavailable.

Templates

Algorithm discovery

Algorithm catalog

Each subfolder of this package is an algorithm package, named in snake_case. A valid algorithm package must:

  • Be a direct subfolder of this directory.

  • Contain a main.py module defining one subclass of tsmadkit.AnomalyDetection.

  • Re-export that class in its __init__.py.

Example structure

algorithms/
    my_algorithm/
        __init__.py     <- from .main import MyAlgorithm
        main.py         <- defines class MyAlgorithm(AnomalyDetection)

Algorithms are imported from their own package, which only imports that algorithm and its dependencies:

from tsmadalg.algorithms.my_algorithm import MyAlgorithm

The algorithm packages are discovered by tsmadalg.tools.registry, which is used by the tsmadalg CLI.
